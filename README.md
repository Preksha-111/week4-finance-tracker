# Personal Finance Tracker

## Project Overview

Personal Finance Tracker is a Python console application that helps users manage their daily expenses efficiently.

## Features

- Add Expenses
- View Expenses
- Remove Expenses
- Search Expenses
- Filter Expenses
- Monthly Reports
- Category Reports
- Budget Management
- Backup & Restore
- CSV Export
- CSV Import
- Expense Prediction
- JSON Data Storage
